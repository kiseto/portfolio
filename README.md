# portfolio

a personal portfolio where i keep the projects i’ve worked on, things i’ve learned, and some of the stuff i enjoy building.

## live site

https://kiseto.github.io/portfolio/

## what’s inside

- project write-ups and screenshots
- academic and personal projects
- a bit about my background and tech stack
- light/dark mode and smooth scrolling

## built with

- next.js
- react
- typescript
- tailwind css
- shadcn/ui
- radix ui
- lucide icons
- lenis
- github pages

## run locally

```bash
npm install
npm run dev
```
